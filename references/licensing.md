# 素材授权速查

> 一句话：**Pexels License 和 CC0 是最省事的两个口子；CC BY 要署名；CC BY-SA 不要碰商业片。**

---

## Pexels License

适用：pexels.com 上的全部视频/图片。

| 允许 | 限制 |
|---|---|
| 免费商用（广告、门店屏、私域、官网、投放） | 不能把**未修改的原片**转售或再分发（素材包、壁纸站、传回素材站） |
| 自由裁剪、调色、加字、二次创作 | 不能暗示画面中的**人物或品牌**为你的产品背书 |
| **不需要署名** | 不能用于诽谤、色情、违法场景 |

- 永久、全球、免费；不随播放量变化。
- 保留了"修改"这一步（剪辑、调色、加字）就已经不是"原样转售"，这是安全的。
- 建议：每条素材保留**素材页链接 + 下载日期截图**，平台审核/客户质询时直接给。

---

## Mixkit Free License（音乐/音效）

| 允许 | 限制 |
|---|---|
| 免费商用、免署名、可剪辑 | 不能把音频**单独**提取转售/再分发 |
| 可与其他素材混合作品 | 不能声称原创 |

注意：Mixkit 的**部分视频**是 Restricted License（不可商用），只下 Free License 的那批；本项目流程不用 Mixkit 视频，只用它的音乐。

## Wikimedia Commons

| 许可 | 商用 | 署名 | 备注 |
|---|---|---|---|
| **CC0 / Public Domain** | ✅ | 不需要 | 最优，随便用 |
| **CC BY** | ✅ | **必须** | 片尾或简介里写"素材：作者 / 许可" |
| **CC BY-SA** | ⚠️ | 必须 | 衍生作品也要按 SA 开放 → **商业广告片不要用** |
| **GFDL** | ⚠️ | 必须 | 条款繁琐，避开 |

CC BY 署名写法（放片尾字卡或发布文案）：

```
画面素材：Netha Hussain, CC BY 4.0, via Wikimedia Commons
```

文件页的 `LicenseShortName` / `UsageTerms` 字段就是权威依据，用 API 直接读：

```bash
curl -s "https://commons.wikimedia.org/w/api.php?action=query&titles=File:XXX&prop=imageinfo&iiprop=url|extmetadata&format=json"
```

## 音乐从哪来

| 来源 | 授权 | 备注 |
|---|---|---|
| Mixkit Free Music | 免费商用、免署名 | 首选，`assets.mixkit.co/music/<id>/<id>.mp3` 直链 |
| Pixabay Music | Pixabay Content License | 免费商用，页面挡 curl，需浏览器 |
| Free Music Archive | 逐曲不同（CC0/CC BY/CC BY-NC） | **NC 的不能商用**，逐条看 |

**绝对不要用**：商业唱片（A-ha、Taylor Swift……）、影视原声、抖音热门 BGM 原曲。这些需要词曲 + 录音双授权，平台检测到会直接限流/下架。

## 合规红线（交付前逐条打勾）

- [ ] 没有把通用素材说成"本团实拍/客人实拍"；
- [ ] 没有出现未经授权的品牌名、logo、门店招牌特写；
- [ ] 自然现象（极光/冰洞/野生动物）没有写"保证"；
- [ ] 价格与当期一致，分班期标注，没有用"起"掩盖差价；
- [ ] 没有绝对化用语（最/第一/唯一/顶级）；
- [ ] 有正脸/可识别人物的素材，确认模特授权或直接不用；
- [ ] 每条素材都能在清单里点回原始页面。

## 存档

1. 成片 + 清单 + 授权说明整体备份；
2. `raw/` 原始文件保留（别只留成片）；
3. 截图保存素材页的授权标识与下载时间；
4. 记录首次发布时间、投放渠道、版本号。
